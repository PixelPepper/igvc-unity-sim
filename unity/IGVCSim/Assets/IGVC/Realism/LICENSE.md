# Realism textures

All textures in `Textures/` are public domain (CC0 1.0) from [ambientCG](https://ambientcg.com).
They were downloaded 2026-10-11 with the user's approval and converted by
`tools/prepare_realism_textures.py`:

- Each map was resized to 1024 px.
- The roughness map was inverted into the alpha of `MetallicSmoothness.png`, as Unity's Built-in Standard shader expects.
