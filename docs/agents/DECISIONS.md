## ADR-001: Role split

2026-10-04 · proposed by user, drafted by claude-opus-5-5, reviewed by gpt-6-astra.

**Context.** Several agents now work on the project: Claude Code (Opus/Sonnet),
Codex (ASTRA, Sol) and Cursor (Grok). Without one decision-maker they duplicated work,
collided on the live simulator and reviewed their own output.

**Decision.** ASTRA (`gpt-6-astra`, high) orchestrates and integrates. Claude Opus 5.5 is
the primary implementer. Claude Sonnet 5.5 reviews code, and GPT-6.1 Sol reviews evidence. There are at
most two implementers plus ASTRA. Reviewers are advisory, ASTRA decides, and the user approves
anything outward-facing or invariant-changing.

**Rationale.** Opus brings the most implementation depth. A cross-vendor evidence reviewer (Sol)
reduces correlated blind spots in Claude-authored work. Prior rounds showed that Sol is
good at provenance and acceptance gaps
([2026-09-30 reviews](../reviews/2026-09-30/REVIEW_SUMMARY.md)). Keeping integration with
one agent preserves the existing "integrator owns builds, lease and interfaces" rule.

**Consequences.** ASTRA is a bottleneck, which is acceptable at two workers.
Reviews bind to a candidate SHA. See [PROTOCOL.md](PROTOCOL.md).

## ADR-002: File-based coordination

2026-10-04 · claude-opus-5-5, revised per gpt-6-astra.

**Context.** The agents run in different products (Claude CLI, Codex app/CLI). None of them can
message another's interactive session directly, and `codex exec` / `claude -p`
start fresh sessions.

**Decision.** Coordination happens through markdown task files with an append-only log in
`docs/agents/` in the **primary checkout only**. The board is generated by
`tools/agents/board.py`. Headless agents return message blocks and ASTRA relays them.
Only ASTRA edits task headers and the board.

**Consequences.** The state is visible in git history and readable by every agent
and the user. A committed `lease` field cannot enforce exclusivity, so the process-held
lease remains authoritative.

## ADR-003: Snapshot-based worker branches

2026-10-04 · claude-opus-5-5.

**Context.** The primary checkout holds 283 uncommitted or untracked changed files
(about 32k lines) relative to HEAD `01709fe`, so HEAD-based worktrees lack current features.

**Decision.** Workers branch from a snapshot commit made by
`tools/agents/snapshot.sh` through a temporary index. Checkpointing the dirty tree into
reviewed scoped commits is task T-0000 and needs user approval.

**Consequences.** Until T-0000 lands, integrating a worker commit can touch files
that are also dirty in the primary tree. ASTRA must stop and checkpoint, never overwrite.

## ADR-004: Competition-informed architecture, no rewrite

2026-10-04 · claude-opus-5-5 and gpt-6-astra, independently.

## ADR-006: Kickoff limits and connection verification

2026-10-04 · gpt-6-astra, relaying the user's approval in Codex Desktop.

**Authority.** The user requested execution of SENDOFF_ASTRA ("lets do it"), then
answered "whatever you think is best" for remaining setup choices and explicitly
selected the proposed promotion threshold. This authorizes the scoped coordination
setup and local snapshot/worktree, not publication or bulk checkpointing T-0000.

**Promotion.** Require at least 3 consecutive full independent audit passes on seed
2027 plus at least 1 full pass on each of 2 held-out seeds, chosen before candidate
testing. Keep every existing health, geometry and policy invariant. 6/6 alone is
not a pass. This is a simulation repeatability gate, not hardware certification.

**Limits.** Default to $20/day reported API-equivalent agent usage and 6 live trials
per America/Los_Angeles calendar day. Reserve $10 for implementation, $5 for each
of two reviews before dispatch; do not start a paid job whose reservation exceeds
the remaining budget. Record actual usage where available; unknown interactive
subscription usage is UNMETERED, never $0, and cannot establish a hard billing cap.
T-0001 uses the existing interactive Claude session, a 35-minute work window and
3 focused offline checks; no additional headless implementer is launched.
Before paid reviews, reconcile available usage; if it cannot be established, stop
and report the limitation rather than claiming the daily cap is enforced.

**Unattended trials.** Allowed within the 6-trial limit only after an explicit
per-task lease grant, on a committed candidate with bounded shutdown. T-0001
revision 1 has no live trial. At most 2 isolated outcome-test instances; no running
session may be stopped or acquired by force. No invariant changes are authorized.

**Setup evidence.** board.py --check and all 5 test_agent_board tests passed.
The first round-trip QUESTION/ANSWER was received in the T-0001 log at 23:24 local.
Claude self-identifies as claude-opus-5-5 in an interactive Desktop Code-tab session.
The default runtime status reported stopped, no workspace Unity player and no
listener on TCP10000; no lease was taken. Only coordination files are committed
at kickoff. The broader dirty-tree checkpoint remains a separate reviewed task.

**Snapshot exclusions.** Three generated folder .meta files under Runtime/artifacts
are excluded with repository-local .git/info/exclude, leaving the files and shared
.gitignore unchanged. They are not source assets and are not removed from disk.

## ADR-007: Conservative reservation for unmetered interactive work

2026-10-04 · gpt-6-astra, under the user's delegated setup/budget choices.

T-0001 finished in the existing interactive session with usage UNMETERED. Actual
spend cannot be reconciled, so ADR-006's hard daily-cap interpretation cannot be
enforced. For the first complete coordination cycle, reserve the full $10 task
allowance (not $0) and allow only the already reserved $5 Sonnet and $5 Sol reviews.

actual charges. No further paid task is dispatched this budget day without known
remaining capacity or a user decision. Record CLI-reported usage when available;
Codex subscription work may likewise lack dollar-equivalent cost. All hard provider
budget claims remain unverified. This supersedes ADR-006's stop-before-review rule
only for these two first-cycle reviews; no retry, live trial or extra model is added.
